# Аудит доступности

**Стандарт:** WCAG 2.1 AA, дополнительно APCA · **Дата:** 12.10.2026 · **Скил:** `design:accessibility-review`

Инструменты: axe-core 4.10 на всех девяти экранах (`scripts/screenshots.py` → `screenshots/report.json`),
собственные проверки клавиатуры, целей нажатия, диалога и масштаба (`scripts/a11y_checks.py`), расчёт контраста
токенов (`scripts/contrast.py`). Проверки с живым экранным диктором (NVDA, VoiceOver) не проводились: в окружении
их нет. Это главное ограничение отчёта.

## Экранные дикторы (по разметке, без живого теста)

| Элемент | Объявляется как | Замечание |
|---|---|---|
| Плашка демо | `note`: «Демо-прототип на синтетических данных…» | Есть на каждом экране |
| Бейдж | «Факт. Источник: Банк России…» | Источник в `aria-label` |
| Статус счёта | «Предложение», «Просрочен» с иконкой | Цвет не единственный признак |
| Путь счёта | список шагов с «пройдено / текущий этап / впереди / ошибка» | `aria-current="step"` |
| Проверки в строке ленты | «УПД в ЭДО: да», «Реестр: ещё нет» | Иконки с текстом для дикторов |
| График | изображение с выводом одной фразой | Плюс таблица данных |
| Тост | `status` или `alert` для ошибок | Ошибка объявляется сразу |
| Часы | время с `aria-live="polite"` | Смена даты объявляется |

## Что осталось

1. Проверить с NVDA и VoiceOver: подсказки Radix внутри таблиц и чтение графиков ECharts (у ECharts своя aria-разметка SVG).
2. Тёмная тема: поднять APCA вторичного текста до Lc 60+ на всех поверхностях.
3. Подсказки «Как посчитано» открываются по наведению и фокусу, но не по нажатию на сенсорном экране. Нужен вариант с раскрытием по нажатию.
