# Развёртывание публичного демо

Образ один для всех площадок: двухэтапный `Dockerfile` (сборка интерфейса на `node:22-slim`, запуск на `python:3.12-slim` от пользователя `app`). В образе по умолчанию включена песочница на посетителя (`SUPPLYLINE_SANDBOX=1`): у каждого своя копия БД, свои часы и свой сброс.

Публикацию и нажатие «Deploy» выполняет владелец аккаунта. Доступность площадок из РФ и условия бесплатных тарифов меняются: **проверить при развёртывании**.

## Переменные

| Переменная | Значение в образе | Зачем |
|---|---|---|
| `PORT` | `8000` | Порт HTTP; площадка может задать свой |
| `SUPPLYLINE_SANDBOX` | `1` | Песочница на посетителя (cookie `sl_sid`, 6 ч) |
| `SUPPLYLINE_MOCK_LATENCY` | `1` | Задержка имитаций 0,1–0,8 с, как при показе |
| `SUPPLYLINE_DB` | `/tmp/supplyline/template.sqlite3` | Шаблонная БД, сидируется при старте |
| `SUPPLYLINE_SESSIONS_DIR` | `/tmp/supplyline/sessions` | Копии посетителей; удаляются через 6 ч, не больше 200 файлов |

Состояние не нужно сохранять между перезапусками: при старте шаблон генерируется заново (seed 42, одинаковые данные).

## Локально

```bash
docker compose up --build
python scripts/smoke.py http://127.0.0.1:8000 --wait 60
```

Без Docker тот же режим:

```bash
SUPPLYLINE_SANDBOX=1 python -m uvicorn api.main:app --port 8000
```

## Render (Docker)

1. Репозиторий на GitHub → в Render «New → Blueprint» → выбрать репозиторий; Render прочитает `render.yaml`.
2. Переменные уже в `render.yaml`; `PORT` Render задаёт сам.
3. Ограничения бесплатного тарифа (проверить): сервис засыпает без трафика, холодный старт 30–60 с; около 512 МБ памяти. Пока идёт сид, `/` показывает «Готовим демо, 10 секунд», API отвечает 503.

## Amvera (деплой через git push)

1. Создать проект в Amvera, тип «Docker»; добавить удалённый репозиторий Amvera: `git remote add amvera <адрес из кабинета>`.
2. `git push amvera sprint-1:master` (ветку назначения уточнить в кабинете).
3. Конфигурация — `amvera.yml` (сборка по `Dockerfile`, порт 8000). Формат файла сверить с документацией Amvera при развёртывании.
4. Переменные `SUPPLYLINE_SANDBOX=1` уже заданы в образе; при необходимости переопределить в кабинете.

## Hugging Face Spaces (Docker)

1. Создать Space с SDK «Docker».
2. В корне Space нужен `README.md` с заголовком:

   ```yaml
   ---
   title: SupplyLine
   sdk: docker
   app_port: 7860
   ---
   ```

3. В настройках Space задать переменную `PORT=7860` (образ слушает `${PORT}`).
4. Ограничения бесплатного Space (проверить): засыпание без трафика, холодный старт; диск не сохраняется (для демо не нужно).

## После развёртывания

```bash
python scripts/smoke.py https://<публичный-адрес> --wait 120
```

Проверяет `/api/health`, дату фактов в `/api/meta`, эффективную ставку 19,67% в `/api/pricing/quote`, загрузку `/` и главного JS, изоляцию двух посетителей («+30 дней» и сброс у первого не меняют второго). Код выхода 1 при ошибке.
