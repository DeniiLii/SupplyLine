# SupplyLine · план внедрения и развития

Версия 02.11.2026. План — гипотезы команды. Каждая фаза открывается только после выполнения ворот.

## 1. Принципы

1. Сначала цифровой факторинг без ЦФА: меньше регуляторных зависимостей, быстрее к деньгам.
2. Каждая фаза проверяет одну гипотезу и имеет числовые ворота.
3. Внешние системы подключаются заменой реализаций портов (`adapters/ports.py`), логика цены и лимитов не меняется.
4. Капитал расходуется по ступеням: фондирование через банк-партнёра в фазе 0 не требует выпуска ЦФА.

## 2. Фазы и ворота

| Фаза | Период | Содержание | Ворота |
|---|---|---|---|
| 0. Цифровой факторинг без ЦФА | 0–6 мес | 3–5 покупателей, 30–50 поставщиков, фондирование банка-партнёра | Просрочка якорей в норме, потери от фрода ≈ 0, время от акцепта до денег < 24 ч |
| 1. ЦФА через партнёра | 6–18 мес | Выпуск ЦФА через оператора, внешние инвесторы, модельный SPV | Внешнее фондирование > 30% портфеля |
| 2. Вторичный рынок и ML-скоринг | 18–36 мес | Торговля требованиями, скоринг на накопленной истории | Объём, достаточный для ликвидности |
| 3. Внешняя торговля | 36+ мес | Экспериментальные правовые режимы, партнёры | Регулирование допускает |

| Месяц | Работы | Результат |

| 1 | Юридическая схема уступки и регресса; письма о намерениях банка-партнёра; найм: продукт, риск, интеграции | Подписанные письма о намерениях; описание схемы |
| 2 | Интервью: 15 покупателей и 30 поставщиков (готовность платить сверх кредита МСП за скорость, API акцепта) | Отчёт интервью; обновлённые `a`, `b`, срок, маржа |

## 7. Риски и ответы

| Риск | Ответ |
|---|---|
| Якоря не дают API акцепта | Начать с портала акцепта и ЭДО-акцепта; отдельный поток интеграций |
| Поставщики уходят к кредиту МСП (цена выше 18,0%) | Продавать скорость и отсутствие залога; пресеты «Рычаги окупаемости» показывают границу потолка рынка 19% |
| Дефолт крупного якоря | Лимит на якоря 15%, страхование требований, резерв капитала |
| Регуляторные изменения по ЦФА | ЦФА только в фазе 1 и только через партнёрского оператора |
| Конкуренты (банки, факторы, платформы) | Узкий сегмент и прозрачная цена; интервью проверяют готовность платить |
| Зависимость экономики от срока и маржи | Чувствительность в модели; обновление после интервью |
