# SupplyLine · финансовая модель, краткое описание

Версия 02.11.2026. Книга `04_Финансовая_модель.xlsx` (листы: Сводка, README, Вводные, Расходы, Ставки, Юнит, Рост, Месяцы, Годы, Сценарии, Чувствит, Стресс, Факты, Проверки). Движок `engine/finmodel.py` повторяет книгу; совпадение подтверждается тестами (допуск 1e-6). Все параметры — гипотезы, кроме отмеченных «Факт». Не прогноз.

## 1. Базовые параметры

Старт операций 01.01.2027; ключевая ставка 14% (Факт); срок финансирования 45 дней; LGD 60%; страховое покрытие 0; `r_opex` 1,2%; `r_margin` 2,4%; кредит МСП 18,0% (Факт) и допустимая премия за скорость 1,0 п.п.; налог на прибыль 25% (Факт); норма капитала 10% от риска организатора; требуемая доходность капитала 20%. Рейтинговая структура портфеля: A 40%, B 45%, C 12,5%, D 2,5% (PD 0,5/1,0/2,0/4,0%).

## 6. Стресс-тест

Покупатель с долей 25% портфеля не платит на 42-м месяце, LGD 60%: потери организатора 1 033 млн ₽ при капитале под риск 676 млн ₽ (покрытие 65%). Безопасная доля одного покупателя 16,4%. При доле 15% капитал покрывает потерю (проверено прогоном модели 02.11.2026). Лимит концентрации в платформе устанавливается 15% (Спринт №1).
