# Графики и показатели

Скил: `dataviz` (вызван до первой строки кода графиков). Палитра проверена `scripts/validate_palette.js` скила.

## Библиотека: ECharts 5 (модульный импорт `echarts/core`)

Почему не visx: нужны водопад, торнадо, воронка, тепловая сетка, подсказки и aria-описания. В ECharts это готовые типы с `aria.enabled`. Скругление 4 px на конце столбца — `itemStyle.borderRadius`. Зазор 2 px — `barGap` плюс граница цвета поверхности. visx дал бы те же картинки втрое большим кодом.

## Палитра

| Фон / контекст | `#C4CAD6` | `#4A5674` | Серия «остальное» |

| Положительное / отрицательное (дивергентная пара) | `#1E8A4C` / `#C0392B` | `#5CC98A` / `#F07A6E` | Только знак величины, всегда со знаком «+/−» в подписи |
| Опорная линия (кредит МСП, потолок, лимит) | `#6B7487` | `#95A0B6` | Сплошная 1 px + текстовая метка у линии |

Цвет закреплён за сущностью: источник фондирования «ЦФА» всегда слот 2, «Баланс» — слот 1. Фильтр не перекрашивает оставшиеся серии.

## Форма под вопрос

| Вопрос экрана | Форма | Цвет |
|---|---|---|
| Из чего состоит дисконт | Горизонтальный водопад: фондирование → потери → издержки → маржа = D | Эмфаза: маржа в акценте, остальное серо-синее; отрицательная маржа красным со знаком «−» |
| При какой премии платформа не дороже кредита | Линия «эффективная ставка от премии» + горизонталь кредита МСП 18,0% + вертикаль точки паритета | 1 серия + опорные линии |
| Оборот по месяцам | Столбцы, одна серия | Акцент |
| Портфель по якорям против лимита | Горизонтальные столбцы + отметка лимита 25% на каждой строке | Эмфаза: превышение красным с иконкой |
| Структура фондирования | Один горизонтальный составной столбец 100% + таблица | Категориальные слоты 1–5 |
| Воронка счетов | Горизонтальные столбцы по этапам, значение на конце | Последовательная: один синий |
| Накопленная ЧП и потребность в капитале (60 мес.) | **Два графика одной оси X**, не двойная ось | Линия ЧП: дивергентная по знаку относительно нуля; капитал — акцент |
| P&L по годам | Таблица + столбцы ПДН по годам со знаком | Дивергентная |
| Что сильнее двигает ПДН Г5 | Торнадо: 11 драйверов, отсортированы по размаху | Дивергентная: рост ПДН зелёный, падение красный, всегда с числом |
| Стресс: доля якоря × LGD | Тепловая сетка 5×4, ячейки ≥ 100% капитала с иконкой | Последовательная от светлого к тёмно-красному + значение в каждой ячейке (20 ячеек — читаемо) |
| Показатели (оборот, остаток, спред, просрочка) | Плитки: подпись · значение · единица · «как посчитано» | Без цвета, кроме статуса |

## Метки и разметка

- Столбец не толще 24 px, скругление 4 px на конце, квадратный у базы.
- Линия 2 px, маркеры ≥ 8 px с кольцом 2 px цвета поверхности.
- Подписи — цветом текста, не цветом серии.
- Подписи выборочно: конец линии, экстремум, последнее значение. Не на каждой точке.
- Оси с единицами: «₽ млн», «% годовых», «месяц».
- Легенда для ≥ 2 серий всегда; до 4 серий — ещё и прямые подписи.
- Двух шкал Y нет нигде.

## Взаимодействие

- Подсказка при наведении: по оси для линий, по метке для столбцов.
- Под каждым графиком переключатель «Таблица данных»: те же числа в `<table>`.
- `aria-label` графика описывает вывод одной фразой («Эффективная ставка выше кредита МСП при любой премии выше 0,4 п.п.»).

## Цифры

- Промпт требует `tabular-nums` для всех чисел. Скил советует пропорциональные цифры для крупных одиночных значений. Решение: в таблицах и осях `tabular-nums`; в плитках и главной цифре тоже `tabular-nums`, как требует бриф (бриф важнее). Различие в ширине при 40 px заметно слабо.
- Главная цифра экрана одна, 40/48 полужирная.
