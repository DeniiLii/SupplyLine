# Спецификация для разработки

Скил: `design:design-handoff`. Источник правды для значений: `web/src/design/tokens.css` (токены),
`web/src/components/ui.tsx` (компоненты), `web/src/components/Chart.tsx` (графики), `web/src/copy/ru.ts` (тексты).
Стек: React 18, TypeScript strict, Vite, Tailwind поверх CSS-переменных, Radix UI, TanStack Query, ECharts 5 (SVG).

## Обзор

Интерфейс показывает расчёты Python-движка. На фронтенде формул нет: только вызовы `/api/*`.
Ползунки отправляют запрос с задержкой 150 мс (`useDebounced`), прошлый ответ остаётся на экране, пока идёт новый
(`keepPreviousData`), поэтому интерфейс не мигает.

## Раскладка

| Параметр | Значение | Токен / класс |
|---|---|---|
| Контейнер | до 1280 px, по центру | `--container`, `.container-page` |
| Поля | 16 px до 640; 24 px до 1024; 32 px шире | `.container-page` |
| Сетка экранов | 12 колонок: параметры 4, результат 8 (симулятор); две колонки графиков с 1280 | `lg:grid-cols-12`, `xl:grid-cols-2` |
| Шаг | 4 px; между карточками 24 px | `--s-6`, `gap-6` |
| Дети сеток | `min-width: 0`, иначе таблицы распирают колонку | `global.css` |
| Прокручиваемые области | `position: relative` и `tabIndex=0` | `global.css`, `.overflow-x-auto` |

### Брейкпоинты

| Ширина | Что меняется |
|---|---|
| < 640 (sm) | Главные цифры 30/38 вместо 40/48; плитки 24/32; итог симулятора над параметрами; меню роли за кнопкой-бургером |
| < 768 (md) | Лента, предложения, факты — карточки вместо таблиц; путь счёта одной строкой «Этап N из 7» |

| Сенсорный ввод (`pointer: coarse`) | Мелкие кнопки `.btn-sm` 44 px |

## Состояния и взаимодействия

| Элемент | Состояние | Поведение |
|---|---|---|
| Кнопка основная | hover / active / disabled | `--primary-hover` / `--primary-press` / прозрачность 0,5, курсор «нельзя» |
| Кнопка при запросе | loading | Спиннер слева от текста, кнопка выключена |
| «Продать счёт» | лимит превышен | Выключена; сверху плашка «Продажа невозможна: правило «…»» с суммой и лимитом |
| «Продать счёт» | успех | Тост «Счёт продан. Деньги придут в течение суток»; карточка и лента обновляются |
| «Попытаться продать повторно» | 409 | Плашка «Действие заблокировано» + тост с текстом про реестр |
| Внешняя система (имитация) | 503 | Тост «Банк-партнёр не подтвердил платёж (сбой имитации)… Выключите сбой и повторите»; требование не уступлено |
| Часы | +N дней | Тост «Часы переведены вперёд. Изменений по счетам: N»; все запросы перечитываются |
| Сценарий фондирования | смена | Тост; новые предложения считаются по новому сценарию |
| Параметр модели | смена | Через 150 мс новый расчёт; старые числа видны до ответа |

## Краевые случаи

| Случай | Что показываем |
|---|---|
| Нет открытых предложений | `EmptyState`: «Переведите часы на день вперёд: якоря акцептуют новые счета» |
| Нет траншей у инвестора | «Выберите сценарий C или M на обзоре и продайте несколько счетов» |
| Поиск без результатов | «Нет счетов с такими условиями. Сбросьте фильтр или переведите часы вперёд» |
| API недоступен | `ErrorBox`: «Сервер не ответил. Проверьте, что запущен API, и повторите» + «Повторить» |
| Ввод вне диапазона | Сообщение под полем «От X до Y ед.»; значение не отправляется |
| Траектория оборота уходит в минус | 422 с текстом движка: «Траектория оборота уходит в минус…» |
| Безубыточность недостижима (сценарий C с потолком) | «н/д» и пояснение «вклад на ₽1 оборота ≤ 0» |
| Отрицательная маржа | Красное число со знаком «−», плашка «Маржа платформы отрицательна» |
| Накопленная прибыль < 0, цена выше потолка, капитал не покрывает дефолт | Плашки-предупреждения над P&L, считаются движком |
| Паритет с кредитом МСП недостижим | Подзаголовок графика: «Паритет недостижим даже при нулевой премии…» |
| Длинные названия поставщиков | Обрезка с многоточием в таблице (220 px), полное имя в заголовке карточки |
| Длинные подписи осей | `hideOverlap`; подписи драйверов торнадо до 260 px с обрезкой и полным текстом в подсказке |
| Медленная сеть | Скелетоны при первой загрузке; при пересчёте прежние данные |
| Ошибка отрисовки экрана | Граница ошибок: «Экран не отрисовался… откройте другой экран из меню» |

## Движение

| Элемент | Триггер | Анимация | Длительность | Кривая |
|---|---|---|---|---|
| Кнопки, вкладки, сегменты | наведение, выбор | цвет фона и текста | 180 мс | `--ease` |
| Узел пути счёта | смена статуса | заливка узла | 180 мс | `--ease` |
| Переключатель | вкл/выкл | сдвиг ручки | 180 мс | `--ease` |
| Графики | новые данные | перерисовка ECharts | 180 мс | по умолчанию |
| Всё | `prefers-reduced-motion` | отключено | 0 | — |

Анимаций при загрузке страницы, «въездов» карточек и анимации шапки нет.

## Доступность

- Порядок фокуса: «Перейти к содержимому» → знак → роль → часы → тема → презентация → меню роли → контент.
- Все интерактивные элементы с кольцом `--focus-ring`; цели не меньше 44 px (мелкие — на сенсорных экранах).
- Цвет никогда не единственный признак: иконка + слово в статусах, знак «+/−» в торнадо, «▲» в сетке стресса.
- Графики: `aria-label` с выводом и таблица данных.
- Подробно: `docs/a11y-report.md`.
