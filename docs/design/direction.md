# Направление дизайна

Скил: `frontend-design` (вызван 12.10.2026 до первого компонента).

## Предмет, аудитория, задача

- **Предмет:** реверсивный факторинг. Счёт поставщика проходит путь «УПД → акцепт якоря → предложение → деньги → оплата якоря».
- **Аудитория:** жюри конкурса и банковские эксперты. Они читают цифры, ищут натяжки и проверяют, откуда взялось каждое число.
- **Задача интерфейса:** показать честную экономику и рабочую механику за три минуты кликов.

## План (первый проход)

**Цвет (4–6 значений)**

| Имя | HEX | Роль |
|---|---|---|
| Глубокий синий | `#1F3270` | Кнопки, активные состояния, ключевые цифры |
| Чернила | `#141B2D` | Основной текст (не тонированный «почти чёрный» ради моды: это синеватый чернильный, родственный основному) |
| Ледяной фон | `#F2F4F8` | Фон страницы, холодный светло-серый |
| Бумага | `#FFFFFF` | Карточки |
| Сигнальный голубой | `#2F7FD8` | Ссылки, основная серия графиков |
| Графит | `#5B6478` | Вторичный текст, подписи |

Шкала синего 50…900 выводится в `tokens.md` вокруг ориентира `#243776`, но сам HEX бренда не используется: основной сдвинут к `#1F3270`.

**Шрифт:** Inter (кириллица, `tabular-nums` для всех чисел). Одна гарнитура. Характер дают размер и вес цифр: дисплейные числа 40/48 полужирные с отрицательным трекингом −0,02 em, подписи 13/18 обычные графитовые. Капслок не используется нигде, даже в подписях к плиткам.

**Раскладка:** контейнер 1280, 12 колонок. Экран читается сверху вниз: вопрос → ответ крупной цифрой → разбор.

```
[шапка: знак · роль ▾ · меню роли · часы]         [плашка «Демо-прототип…» — тонкая, всегда видна]
┌──────────────── вывод экрана одной фразой ─────────────────┐
│ 19,67%            ← главная цифра, левое выравнивание       │
│ эффективная ставка поставщика   ·  кредит МСП 18,0%         │
└─────────────────────────────────────────────────────────────┘
┌ параметры (4 кол.) ┐ ┌ результат и графики (8 кол.) ───────┐
```

Выравнивание: всё по левому краю, числа в таблицах по правому. Центрирование не используется.

**Принципы**

1. Каждый экран начинается с одного числа, которое отвечает на вопрос экрана, и одной фразы, что оно значит. Неудобные числа (убыток, «дороже кредита») показываются так же крупно, как удобные.
2. Происхождение видно. У каждого параметра бейдж «Факт» или «Гипотеза»; у каждого вычисленного числа подсказка «как посчитано».
3. Одна смелость: **линия с узлами.** Знак SupplyLine — горизонтальная линия с узлом. Тот же мотив — единственный декоративный элемент интерфейса: путь счёта по статусам в ленте и карточке, шкала «акцепт → деньги», дорожная карта с воротами. Больше нигде нет декора: ни градиентов, ни иллюстраций, ни теней.
4. Иерархия радиусами, а не тенями: карточка 20 px, вложенная панель и поля 12 px, чипы 999 px. Тени нет, только граница 1 px.
5. Цвет несёт смысл. Синий — действие и «наше» число. Зелёный, янтарный, красный — только статусы и всегда с иконкой и словом.

## Проверка плана против шаблонов

| Черта | Было в первом наброске | Решение |
|---|---|---|
| Набор одинаковых SaaS-карточек | Все блоки в одинаковых карточках с тенью | Тени убраны; радиусы разные по уровню; таблицы и графики стоят на карточке без вложенных «карточек в карточках» |
| Капслок-ярлыки над заголовками | «ЭКОНОМИКА», «ПОРТФЕЛЬ» над блоками | Убраны. Заголовок блока — обычная фраза-вопрос («Сколько получит поставщик») |
| Большая цифра + градиент | Плитки с градиентной подложкой | Подложки нет; цифра на белом, единица меньше и графитовая |
| Моноширинный шрифт для данных | Хотелось для ключа реестра | Только для SHA-256 ключа, где посимвольное сравнение — смысл. Остальное Inter tabular |
| Стрелки «→» в кнопках | «Продать →» | Глагол без стрелки: «Продать счёт» |
| Нумерация 01/02/03 | В разделе слоёв архитектуры | Оставлена только там, где это порядок: семь слоёв и четыре фазы дорожной карты |

## Чего не делаем

Логотип, название, талисман, иллюстрации, анимация шапки, шрифты ВТБ (Omega UI, VTB Group UI) не используются. Знак SupplyLine нарисован заново: слово «SupplyLine» Inter Semibold и линия с одним узлом слева.

## Движение

150–200 мс, ease-out, только в ответ на действие: раскрытие карточки счёта, смена статуса (узел линии заполняется), тост. `prefers-reduced-motion` отключает всё.
