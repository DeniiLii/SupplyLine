# Критика дизайна

Скил `design:design-critique` применён к снимкам всех экранов (1440 и 390 px, светлая и тёмная темы).
Параллельно работал независимый субагент-ревьюер: он видел только скриншоты и `tokens.md`, без кода и контекста.
Его 21 замечание сведено в таблицу ниже вместе с моими. Статус показывает, что сделано.

## Общее впечатление

Каждый экран открывается одной цифрой-ответом, неудобные выводы («дороже кредита МСП»,
«накопленная прибыль отрицательна», «капитал не покрывает дефолт якоря») показаны так же крупно, как удобные.
Больше всего проблем было в трёх местах: карточка счёта допускала противоречие (продажа доступна при превышенном
лимите), мобильная версия (таблицы, оси, порядок блоков) и внутренний жаргон на экранах для жюри.

## Осознанно оставлено

| Замечание ревьюера | Почему не меняли |
|---|---|
| Таблицы модели (P&L, матрица 4×2, юнит-экономика) на телефоне прокручиваются вбок, а не превращаются в карточки | Это финансовые таблицы «показатель × год»: в карточках сравнение по годам теряется. Прокрутка доступна с клавиатуры, заголовок строки виден. Лента, факты и предложения на телефоне — карточки |
| Плашка «Дороже кредита МСП» визуально сильнее главной цифры | Принцип честности брифа выше красоты: жюри должно увидеть вывод сразу. Цифра остаётся самой крупной на экране |
| Копейки в карточке счёта | Компоненты дисконта округляются до копеек и в сумме дают D ровно; без копеек сумма не сходится на глаз |
| «SL-2026-КРУПНЫЙ» выбивается из формата номеров | Это сюжетный счёт для показа; жюри находит его поиском по слову «КРУПНЫЙ» |
| Шапка на телефоне занимает ~150 px | Часы — главный инструмент демонстрации, прятать их в меню нельзя. Мелкие кнопки на сенсорных экранах поднимаются до 44 px (`pointer: coarse`) |
| Шесть плиток обзора одного веса | Плитки повторяют список из брифа (оборот, остаток, спред, просрочка, вне баланса, фрод). Главный вывод экрана — ворота ниже |

## Что работает

- Одна цифра-ответ в начале каждого экрана; неудобные числа не прячутся.
- Бейджи «Факт / Гипотеза» с источником в подсказке у каждого параметра.
- «Линия с узлами» — единственный декоративный мотив, и он несёт смысл: путь счёта, дорожная карта.
- Под каждым графиком есть таблица данных.
