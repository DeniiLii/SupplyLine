# Токены и компоненты SupplyLine

Скил: `design:design-system` (вызван после `direction.md`, до экранов). Файл токенов: `web/src/design/tokens.css`.
Контраст проверяет `scripts/contrast.py` (WCAG 2.1 и APCA W3 0.0.98G).

## Типографика

Inter (Google Fonts, кириллица), все числа `font-variant-numeric: tabular-nums`. Капслок не используется.

| Токен | Размер / интерлиньяж | Вес | Где |
|---|---|---|---|
| display | 40 / 48 | 600, трекинг −0,02 em | Главная цифра экрана |
| h1 | 28 / 36 | 600 | Заголовок экрана |
| h2 | 20 / 28 | 600 | Заголовок блока |
| body | 16 / 24 | 400 | Текст |
| small | 14 / 20 | 400/500 | Таблицы, поля |
| caption | 13 / 18 | 400 | Подписи, бейджи |

Числа: `ru-RU`, неразрывный пробел для тысяч, «₽», «млн», «млрд»; проценты с запятой.

## Пространство, радиусы, движение

- Шаг 4 px: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64.
- Контейнер 1280, 12 колонок; поля 16 px до 640, 24 px до 1024, 32 px шире.
- Радиусы: карточка 20, панель и поле 12, чип 999. Теней нет.
- Фокус: кольцо 2 px `--focus` с зазором 2 px цвета поверхности (`--focus-ring`).
- Цели нажатия от 44 px.
- Движение 180 мс, `cubic-bezier(.2,.7,.2,1)`; при `prefers-reduced-motion` — 0.

## Компоненты (web/src/components)

| Компонент | Варианты | Состояния | Доступность |
|---|---|---|---|
| Button | primary, secondary, ghost (текстовая), danger | default, hover, active, focus, disabled, loading | `<button>`, `aria-busy` при загрузке |
| Field (число/текст) | с единицей справа | default, focus, error, disabled | `<label for>`, ошибка через `aria-describedby` |
| SliderField | ползунок + числовой ввод | синхронны; ввод с дебаунсом 150 мс | Radix Slider: стрелки, Home/End, `aria-valuetext` с единицей |
| Switch | — | on, off, focus, disabled | Radix Switch, `role=switch` |
| Segmented | 2–5 вариантов | выбран, наведение, фокус | Radix ToggleGroup type=single, стрелки |
| Tabs | — | активная, наведение, фокус | Radix Tabs |
| StatusChip | по статусу счёта: нейтральный, успех, предупреждение, ошибка, процесс | — | иконка + текст, цвет не единственный носитель |
| Badge | «Факт», «Гипотеза», «Факт и гипотеза», «Данные 2023» | с подсказкой-источником | `title` и Radix Tooltip по фокусу |
| Metric (плитка) | обычная, акцентная, отрицательная | загрузка (скелетон) | число + единица + подпись + «как посчитано» |
| Card | уровень 1 (20 px) | — | `section` с заголовком h2 |
| Panel | вложенная (12 px, `--surface-sunken`) | — | — |
| DataTable | обычная, плотная | sticky-шапка, наведение строки, выбранная строка | `<table>`, `<th scope>`; на телефоне — карточки |
| Dialog | — | открыт | Radix Dialog: фокус-ловушка, Esc |

| EmptyState | — | — | заголовок + что сделать |
| Hint | термин с пунктирным подчёркиванием | по наведению и фокусу | Radix Tooltip |
