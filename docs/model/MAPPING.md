# Excel → движок

Книга-эталон: `docs/model/SupplyLine_financial_model.xlsx`. Движок: `engine/finmodel.py`.
Паритет проверяет `tests/test_excel_parity.py` (допуск 1e-6 относительный).

| Лист Excel | Что считает | Функция движка | Что сверяет тест |
|---|---|---|---|
| Вводные | Все параметры и переключатели | `FinParams` (значения по умолчанию = ячейки листа) | Ячейки для экспорта: `api/finmodel_meta.py::PARAMS` |
| Расходы | Постоянные расходы по статьям | `fixed_opex`, `fixed_opex_breakdown` | `Расходы!B11:F11` |
| Рост | Узлы v₀…v₅ месячной траектории | `nodes` | `Рост!B7:G7` |
| Ставки, B4–B14 | PD портфеля, r_EL, коэффициенты остатка, потолок | `pd_port`, `el_rate`, `r_el`, `balance_coefs`, `cap_discount` | `Ставки!B4:B6, B8:B10, B12:B14` |
| Ставки, блоки A/B/C/M | Веса, w_on, премии, r_fund, доля риска, цены, маржа по годам | `rates(p, scenario, year)` → `Rates` | косвенно через Месяцы, Годы, Сценарии |
| Ставки, B114–B125 | Выбранный сценарий | `rates(p, p.scenario, y)` | косвенно |
| Юнит | Экономика одного счёта | `unit_economics` | `Юнит!B7:I19` (8 вариантов × 13 строк) |
| Месяцы | 60 месяцев, 27 показателей | `trajectory`, `monthly` | `Месяцы!E3:AE62` (1 620 ячеек) |
| Годы | Годовая сводка и KPI | `yearly`, `kpis` | `Годы!B3:F37`, `B39:B47` (кроме B42) |
| Сценарии | 4 сценария × 2 режима, годовой расчёт | `scenario_annual`, `scenario_matrix` | 8 блоков × 20 строк × 5 лет, сводка `C3:O10` |
| Чувствит | Мини-модель Г5, 11 драйверов × 2 кейса | `sensitivity`, `_sens_case` | `AJ43`, `D5:H15` |
| Стресс | Дефолт крупнейшего якоря, сетки | `stress` | `B4:B22`, `B27:E31`, `B35:E39`, `B44:E48` |
| Факты | Рыночные факты и оценка доли | `api/content.py::FACTS` | не сверяется: текст |
| Сводка | Ключевые показатели и графики | экран «Портфельная модель» | не сверяется: дублирует Годы |
| Проверки | Контрольные тождества | `checks` (18 тождеств) | `tests/test_finmodel.py::test_checks_all_green` |

## Расхождения книги с README

- Листа «Проверки» в книге нет, хотя README книги на него ссылается. Тождества реализованы в движке (`checks`).
- `Годы!B42` («Месяц окупаемости накопленной прибыли») содержит `#REF!`; кэшированное значение «нет в горизонте».
  Движок считает месяц окупаемости как первый месяц с накопленной ЧП > 0; в базовом варианте это тоже «нет».
- `Месяцы!F3` содержит `#REF!` в ветке `IF(A3>=3, …)`, которая для месяца 1 не вычисляется; значение верное.
  При пересчёте в LibreOffice ошибка может проявиться. Формулу стоит заменить на `0`.
