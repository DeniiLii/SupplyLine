# Видео-демо: текст закадрового голоса

Видео `deliverables/SupplyLine_demo.mp4` пишет `scripts/record_demo.py`: Playwright проходит тур «Показать за 3 минуты» (1440×900, без звука, субтитры на экране). Длительность 2:09. Текст ниже — для озвучки при желании, по 1–2 предложения на шаг. Числа в нём берутся с экрана; если параметры модели изменятся, перезапишите видео.

| Время | Шаг | Голос |
|---|---|---|
| 0:00 | Заставка | SupplyLine — цифровой реверсивный факторинг для среднего бизнеса. Покажу продукт за две минуты на синтетических данных. |
| 0:05 | 1. Симулятор | Цена считается от риска покупателя-якоря. Продажа счёта выходит дороже кредита МСП, и экран говорит об этом прямо: поставщик платит за деньги в течение суток без залога. |
| 0:20 | 2. Крупный счёт | Этот счёт превышает потолок концентрации 15% на одного якоря. Продажа недоступна, правило и суммы видны в карточке. |
| 0:33 | 3. Продажа | Обычный счёт: УПД найден в ЭДО, якорь акцептовал, лимиты в норме. Требование продано и записано в реестр. |
| 0:47 | 4. Повторная продажа | Пробуем продать то же требование ещё раз. Реестр отказывает: двойное финансирование невозможно. |
| 0:59 | 5. +1 день | Через день деньги у поставщика. Моделируем, что якорь не заплатил в срок. |
| 1:12 | 6. +30 дней | Через 30 дней просрочка переходит в регресс к поставщику по договору. |
| 1:25 | 7. Стресс-тест | Если якорь с долей 25% объявит дефолт, капитала не хватит. Поэтому лимит платформы 15%: при нём капитал покрывает потерю. |
| 1:38 | 8. Ворота фазы 0 | Пять показателей решают, переходить ли к следующей фазе: одобрения, просрочка, фрод, время до денег и внешнее фондирование. |
| 2:02 | Финал | Это демо-прототип на синтетических данных, не банк и не оферта. Ссылки на код и демо — в описании. |

Перезапись: сервер с `SUPPLYLINE_MOCK_LATENCY=1`, затем

```bash
python scripts/record_demo.py http://127.0.0.1:8000 --repo <ссылка на репозиторий> --demo <публичный адрес>
```

Кадры для проверки (каждые 20 с) — `deliverables/video_frames/`.
